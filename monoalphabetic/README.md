# Group 10 - Monoalphabetic Substitution Cipher

## Aim
Implement a monoalphabetic substitution cipher and perform
cryptanalysis using frequency and pattern analysis.

## Group
10

## Assigned Page
Group Number + 30 = 40

## Language
C++

## Functions Implemented

1. frequency_analysis()
2. word_frequency_analysis()
3. pattern_analysis()
4. apply_substitution()
5. display_partial_plaintext()
6. verify_solution()

## Steps

1. Read plaintext
2. Encrypt plaintext
3. Generate ciphertext
4. Perform letter frequency analysis
5. Perform word frequency analysis
6. Perform pattern analysis
7. Propose substitutions
8. Apply substitutions
9. Examine partial plaintext
10. Recover key
11. Verify by re-encryption

## Compilation

g++ -std=c++17 main.cpp -o monoalphabetic

## Execution

./monoalphabetic
