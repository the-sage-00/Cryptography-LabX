\# IoT Device Management



\## Group 10



This application demonstrates a small IoT Device Management system.



\## Core Functionalities



1\. Smart device registration

2\. Device status monitoring

3\. Firmware upload

4\. Configuration management



\## Vulnerabilities Demonstrated



1\. Command Injection

2\. Path Traversal

3\. Missing Authentication



\## Technology



\- Python

\- Semgrep

\- Git/GitHub



\## Purpose



The application is intentionally implemented with selected vulnerabilities

for security testing and SAST analysis as part of the laboratory assignment.



A secure version is developed after identifying the vulnerabilities.
